
# 🧠 Customer Segmentation Project

## 📌 Overview
This project focuses on segmenting customers based on their behavior and demographics using clustering techniques.

## 🛠 Tools Used
- Python (Pandas, Scikit-learn)
- Matplotlib

## 📊 Features
- Customer Segmentation using K-Means Clustering
- Analysis of Spending Score vs Income
- Identification of Target Customer Groups

## 📂 Files
- customer_segmentation.csv → Dataset used

## 🚀 Insights
- High income & high spending customers are premium targets
- Low income & low spending customers require different strategies
- Helps in marketing personalization
